# Spaced-Repetition-Helper
This is an app made in Godot that helps you practice spaced repetition. Try it out at [itch.io](https://viywolf.itch.io/spaced-repetition-helper)

![](https://github.com/viywolf/Spaced-Repetition-Helper/blob/main/Screenshot%202026-10-18%20220121.png)

## What is it?
Based on the concept 'spaced repetition', the app automatically spaces out flashcards for you to revise. With exam season coming up for me and many other people, I thought this would be a super relevant project to work on!

Currently it:
- Allows you to add and edit flashcards
- Manually advance time and revise flashcards every few 'days'

Planned additions:
- Drastically better UI (sorry about the current ui!)
- Local saving

Potential additions?:
